## מבוא
במטלה זו תתבקשו לממש  **sudoku solver**. מטרת המטלה היא לתרגל עבודה עם מבני נתונים דו-ממדיים (מטריצות) ומימוש לוגיקה אלגוריתמית מורכבת באמצעות רקורסיה (Backtracking).

    [8, 0, 0, 0, 6, 0, 0, 0, 3],
    [4, 0, 0, 8, 0, 3, 0, 0, 1],
    [7, 0, 0, 0, 2, 0, 0, 0, 6],
